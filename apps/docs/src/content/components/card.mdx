## Accessibility

- Use a list when presenting a group of related cards. The group example wraps each card in an `<li>`.
- Card titles use styled `<div>` elements in the React component. Use a suitable heading element when the title should appear in the page’s heading structure.
- Give informative images descriptive alternative text. Use an empty `alt` attribute when the image is decorative, as in these examples.
