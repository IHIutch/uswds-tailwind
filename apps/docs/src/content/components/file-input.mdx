## Component API

### Initialization

```js
import { fileInputInit } from '@uswds-tailwind/compat/file-input'

fileInputInit()
```

`FileInput` is the corresponding instance class. Initialize after all parts and the preview template exist.

### Anatomy

Set authored attributes in your HTML. The component manages generated attributes. Types describe HTML attribute values.

Use `data-part="file-input-root"` with these descendants:

#### `file-input-label`

Required label.

#### `file-input-dropzone`

Required drop target.

#### `file-input-input`

Required native file input.

<ApiTable label="file-input-input attributes">

| Attribute | Type | Description |
| --- | --- | --- |
| `accept` | `comma-separated string` | **Authored.** Accepted file types. |
| `disabled` | `boolean attribute` | **Authored.** Disables selection. |
| `multiple` | `boolean attribute` | **Authored.** Allows the native input to select multiple files. |
| `data-errormessage` | `string` | **Authored.** Message displayed for an invalid file type. |

</ApiTable>

#### `file-input-instructions`

Required visible selection instructions.

#### `file-input-sr-status`

Required announcement region.

#### `file-input-preview-header`

Required preview heading.

#### `file-input-preview-list`

Required preview container.

#### `file-input-preview-item`

Required initial template inside the preview list.

#### `file-input-preview-item-icon`

Optional preview icon template.

#### `file-input-preview-item-content`

Optional filename template.

#### `file-input-error-message`

Optional visual error message.

The wrapper owns the generated preview children. Keep the file input in the form with a meaningful label and `name`.

### Configuration

The wrapper reads `accept`, `disabled`, and `data-errormessage` during construction; these DOM-derived values override their corresponding constructor options, including when an attribute is absent.

`accept` is a file-picker hint and client-side type constraint, not a server validation rule. The component manages selection and previews; it does not upload files. The application owns submission and server validation.

### Lifecycle

Retain explicitly constructed instances and call `destroy()` before removing the markup. The legacy convenience initializer returns no instance array.

See [instance lifecycle](/javascript#instance-lifecycle).

Keep status and error elements separate from generated preview children.
