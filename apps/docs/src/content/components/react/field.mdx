## Examples

Use `Field.Root` when you want a form control to share a label, hint, and validation state. Wrap one control per field. `Field.Label` and `Field.Description` provide the control’s label and accessible description; `Input`, `Textarea`, and `Select.Field` read that context.

### Error message

Set `invalid` on `Field.Root` after validation. `Field.ErrorMessage` then appears, and the control receives `aria-invalid` and a description that includes the error. `required` and `disabled` on the root also reach the control.

### Fieldset

Use `Fieldset.Root` to group related controls and `Fieldset.Legend` to name the group. Each nested `Field.Root` keeps its own label and control association.
