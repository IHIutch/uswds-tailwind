On narrow screens, `stacked` hides the visual header row and places each cell on its own line. Keep the native caption and column headers, and add a `data-label` that matches its column heading to every body cell.

### Sortable

<ReactPreview variant="Sortable" example="table-sorted-demo" playgroundDependencies={{ '@tanstack/react-table': '9.2.4' }}>
  <TableSortedDemo client:load />
</ReactPreview>

Install `@tanstack/react-table` to sort the data. `Table.Root` supplies sort buttons, `aria-sort`, and a status announcement; `onSortChange` forwards the requested column and direction to TanStack Table, whose row model supplies the reordered rows. Keep the Table sort state and row order in sync so the announcement describes the visible data.
