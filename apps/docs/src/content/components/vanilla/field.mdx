---
title: "Field"
description: "Pair a form control with its label, hint, and validation message using the field pattern."
---

Use one field for each form control. In React, `Field.Root` shares the label, description, and validation state with an `Input`, `Textarea`, or `Select.Field` inside it. Use `Fieldset.Root` and `Fieldset.Legend` to name a group of related fields. The Vanilla examples show the equivalent HTML relationships.

In Vanilla, connect each label with `for` and each hint or error with `aria-describedby`. Set `aria-invalid="true"` when validation fails. There is no separate Field initializer.

## Examples

### Input and hint

<ComponentPreview title="Input and hint" code={`
  <div class="max-w-xs">
    <label for="field-email" class="block">Email address</label>
    <div id="field-email-hint" class="text-gray-50">We will send updates to this address.</div>
    <input id="field-email" type="email" aria-describedby="field-email-hint" class="p-2 w-full h-10 border border-gray-60 focus:outline-offset-0 focus:outline-4 focus:outline-blue-40v bg-white" />
  </div>
`} />

### Fieldset

Use a `fieldset` and `legend` for a group of related controls. Keep each control's label associated with its own input.

<ComponentPreview title="Fieldset" code={`
  <fieldset class="max-w-xs">
    <legend class="leading-snug max-w-mobile-lg mb-3">Personal information</legend>
    <div class="space-y-4">
      <div>
        <label for="field-first-name" class="block">First name</label>
        <input id="field-first-name" type="text" class="p-2 w-full h-10 border border-gray-60 focus:outline-offset-0 focus:outline-4 focus:outline-blue-40v bg-white" />
      </div>
      <div>
        <label for="field-last-name" class="block">Last name</label>
        <input id="field-last-name" type="text" class="p-2 w-full h-10 border border-gray-60 focus:outline-offset-0 focus:outline-4 focus:outline-blue-40v bg-white" />
      </div>
    </div>
  </fieldset>
`} />
