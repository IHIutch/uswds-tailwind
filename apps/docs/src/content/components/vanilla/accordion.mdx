## Component API

### Initialization

Run once after the accordion markup exists:

```js
import { accordionInit } from '@uswds-tailwind/compat/accordion'

accordionInit()
```

For an instance you can control, use `Accordion.getOrCreateInstance(root, options)`. See [shared instance methods](/docs/vanilla/javascript#instance-lifecycle).

### Anatomy

Set authored attributes in your HTML. The component manages generated attributes. Types describe HTML attribute values.

#### `root`

Groups the accordion items.

<ApiTable label="accordion root attributes">

| Attribute | Type | Description |
| --- | --- | --- |
| `data-scope` | `"accordion"` | **Authored.** Identifies the component scope. |
| `data-part` | `"root"` | **Authored.** Identifies this part. |
| `data-multiple` | `boolean-like attribute` | **Authored.** Allows several open panels. Bare attribute is true; omission or `"false"` is false. Overrides the `multiple` option, even when omitted. |

</ApiTable>

#### `item`

One panel, containing its trigger and content.

<ApiTable label="accordion item attributes">

| Attribute | Type | Description |
| --- | --- | --- |
| `data-part` | `"item"` | **Authored.** Identifies this part. |
| `data-value` | `string` | **Authored.** Required unique, nonempty item value; `id` is used as a fallback. |
| `data-state` | `"open" \| "closed"` | **Authored.** Use `"open"` to expand initially. In single-open mode, only the first marked item is used. `defaultValue` overrides these markers. |
| `data-state` | `"open" \| "closed"` | **Generated.** `"open"` or `"closed"`; use for styling. |

</ApiTable>

#### `item-trigger`

Toggles its panel. Place inside a heading when introducing a section.

<ApiTable label="accordion item-trigger attributes">

| Attribute | Type | Description |
| --- | --- | --- |
| `data-part` | `"item-trigger"` | **Authored.** Identifies this part. |
| `data-state` | `"open" \| "closed"` | **Generated.** `"open"` or `"closed"`; use for styling. |
| `aria-expanded` | `"true" \| "false"` | **Generated.** Whether the content is expanded. |
| `aria-controls` | `ID reference` | **Generated.** ID of the associated content. |

</ApiTable>

#### `item-content`

Panel content, inside the same item as its trigger.

<ApiTable label="accordion item-content attributes">

| Attribute | Type | Description |
| --- | --- | --- |
| `data-part` | `"item-content"` | **Authored.** Identifies this part. |
| `data-state` | `"open" \| "closed"` | **Generated.** `"open"` or `"closed"`; use for styling. |
| `hidden` | `boolean attribute` | **Generated.** Present when closed. |

</ApiTable>

### Configuration

Pass these JavaScript options to the instance constructor or factory. Authored configuration attributes are read during construction.

<ApiTable label="accordion JavaScript options">

| Option | Description |
| --- | --- |
| `defaultValue` | `string[]`. Initial expanded item values; overrides item state markers. |
| `value` | `string[]`. Controlled expanded values; takes precedence over `defaultValue`. |
| `id` | Instance identifier; defaults to the root ID or a generated value. |
| `ids` | Override root, item-trigger, and item-content IDs for composition. |

</ApiTable>

### Methods

<ApiTable label="Accordion instance methods">

| Method | Returns | Description |
| --- | --- | --- |
| `open(value)` | `Promise<void>` | Requests expansion of the item. |
| `close(value)` | `Promise<void>` | Requests collapse of the item. |
| `toggle(value)` | `Promise<void>` | Requests the opposite expanded state. |
| `destroy()` | `void` | Stops the instance and removes its lookup. Does not restore the original HTML. |

</ApiTable>

```js
import { Accordion } from '@uswds-tailwind/compat/accordion'

const accordion = Accordion.getOrCreateInstance(
  '[data-scope="accordion"][data-part="root"]',
)

await accordion.open('one')
```

Pass the item’s `data-value` (or fallback `id`) as the `value` argument. Promises settle the queued update, not CSS transitions. When using controlled state, your application must supply the updated value.

See [initialization and cleanup](/docs/vanilla/javascript#instance-lifecycle).

### Callbacks

<ApiTable label="Accordion callbacks">

| Callback | Payload | When it runs |
| --- | --- | --- |
| `onValueChange` | `{ value: string[] }` | Expanded values change, or a controlled change is requested. |

</ApiTable>

Pass callbacks in instance options. They are JavaScript functions, not emitted DOM events.

### Accessibility

- Supply meaningful button text and appropriate heading levels.
- Enter and Space activate the focused button.
