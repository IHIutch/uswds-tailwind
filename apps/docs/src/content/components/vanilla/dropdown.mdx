## Component API

### Initialization

Run `dropdownInit()` from `@uswds-tailwind/compat/dropdown` after the markup exists, or use the auto initializer described in the [JavaScript guide](/docs/vanilla/javascript).

### Parts

`root` contains `trigger` and `content`. Each `item` belongs inside `content`. The initializer manages open state, focus, and keyboard interaction.
