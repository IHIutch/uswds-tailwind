## Component API

### Styling

Default, striped, borderless, compact, scrollable, and sticky tables use native table markup and Tailwind classes. They do not need `tableInit()`.

Preserve captions, column headers, row-header scopes, and keyboard access to scroll containers.

### Sorting markup

Run `tableInit()` from `@uswds-tailwind/compat/table` after the markup exists. It returns initialized `Table` instances.

Use `data-scope="table" data-part="root"` on a wrapper containing a `table` part and a separate `sr-status` part. Both are required. The table must have a `<tbody>`; the wrapper sorts its first body. Author the status region with `class="sr-only"`; the runtime supplies `aria-live="polite"` and announcement text.

Mark sortable `<thead>` headers with `data-sortable` and place a native button inside each header. Presence of `data-sortable`, including `false`, enables sorting. The wrapper generates `header` and `sort-trigger` parts on these elements.

Rows and cells are native markup, not anatomy parts. The wrapper generates `data-sort-active="true"` on cells in the sorted column.

<ApiTable label="table sorting attributes">

| Element | Attribute | Description |
| --- | --- | --- |
| Root | `data-sort-column` | Authored nonnegative integer column index for initial sorting. |
| Root | `data-sort-direction` | Authored `ascending` or `descending`; defaults to an initially sorted header's direction, then `ascending`. |
| Sortable header | `aria-sort` | May author `ascending` or `descending` for initial sorting when no valid root column is supplied. Generated after initialization and removed from unsorted headers. |
| Cell | `data-sort-value` | Authored comparison value. Nonempty values take precedence over `data-sort`, rendered text, then text content. |

</ApiTable>

Numeric values compare as numbers when both cells contain nonempty numeric strings. Other values use locale comparison with numeric ordering and ignored punctuation.

### Configuration

<ApiTable label="table options">

| Option | Description |
| --- | --- |
| `defaultSortDescriptor` | Initial `{ column: number, direction: 'ascending' \| 'descending' }`, or `null`. Takes precedence over authored sorting attributes, including an explicit `null`. |
| `sortDescriptor` | Controlled descriptor, or `null` for unsorted. Your application must update it after requests. |
| `captionText` | Announcement caption; defaults to rendered caption text. |
| `columnNames` | Record of column indices to announcement names; defaults to rendered sortable header text. |
| `id`, `ids` | Instance identifier and generated root, header, sortTrigger, and srStatus IDs. |
| `onSortChange` | Receives `{ sortDescriptor }` for sort changes or controlled requests. This is a JavaScript callback. |

</ApiTable>

### Methods and cleanup

Use `Table.getOrCreateInstance(root, options)` to configure an instance. `api.setSortDescriptor(descriptor)` requests a sort update and returns `void`. `api.sortDescriptor` and `api.announcement` expose current state.

Clearing the descriptor removes sort state but does not restore the original row order. Initialization requires an authored announcement element; it does not create a sibling region. Call `destroy()` before removing markup. See [instance lifecycle](/docs/vanilla/javascript#instance-lifecycle).
