## Component API

### Initialization

```js
import { characterCountInit } from '@uswds-tailwind/compat/character-count'

characterCountInit()
```

Initialize after the markup exists. `CharacterCount` is the corresponding instance class. See [initialization and cleanup](/docs/vanilla/javascript#instance-lifecycle).

### Anatomy

Set authored attributes in your HTML. The component manages generated attributes. Types describe HTML attribute values.

Use `data-part="character-count-root"` with these descendants:

#### `character-count-label`

Optional label for the input.

<ApiTable label="character-count-label attributes">

| Attribute | Type | Description |
| --- | --- | --- |
| `data-invalid` | `presence attribute` | **Generated.** Present when over the limit. |

</ApiTable>

#### `character-count-input`

Required input or textarea.

<ApiTable label="character-count-input attributes">

| Attribute | Type | Description |
| --- | --- | --- |
| `maxlength` | `integer` | **Authored.** Maximum length. Converted with `Number()` at construction; overrides the `maxLength` option, even when missing or empty. Missing or empty means no limit. Also constrains native browser entry. |
| `data-invalid` | `presence attribute` | **Generated.** Present when over the limit. |

</ApiTable>

#### `character-count-status`

Required visual count message.

<ApiTable label="character-count-status attributes">

| Attribute | Type | Description |
| --- | --- | --- |
| `data-invalid` | `presence attribute` | **Generated.** Present when over the limit. |
| `aria-hidden` | `"true" \| "false"` | **Generated.** Hides the visual count from assistive technology. |

</ApiTable>

#### `character-count-sr-status`

Required screen-reader count message.

<ApiTable label="character-count-sr-status attributes">

| Attribute | Type | Description |
| --- | --- | --- |
| `aria-live` | `"polite"` | **Generated.** `"polite"`; announces count updates. |

</ApiTable>

### Accessibility

- Provide a visible label and a static limit hint linked with `aria-describedby`.
- Keep both status elements: the visual status uses `aria-hidden`; the separate announcement region uses `aria-live="polite"`.

### Lifecycle

Retain explicitly constructed instances and call `destroy()` before removing their markup; the legacy initializer does not return an instance array.
