## Accessibility

- Use `role="alert"` for messages that demand immediate attention, such as error or emergency alerts. Use `role="status"` for advisory messages.
- If an alert has a title, consider whether it needs a heading in the page structure. The component uses a styled `div` for its title; use an appropriate heading element when the title should appear in heading navigation.
