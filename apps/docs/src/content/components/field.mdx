---
title: "Field"
description: "Group a form control with its label, helpful instructions, and validation message."
---

Use one field for each form control. In React, `Field.Root` shares the label, description, and validation state with an `Input`, `Textarea`, or `Select.Field` inside it. The Vanilla examples show the equivalent HTML relationships.

In Vanilla, connect each label with `for` and each hint or error with `aria-describedby`. Set `aria-invalid="true"` when validation fails. Apply the [USWDS success style](https://designsystem.digital.gov/components/text-input/) explicitly when validation succeeds. There is no separate Field initializer.

## Examples

### Input and hint

<ComponentPreview title="Input and hint" code={`
  <div class="max-w-xs">

    <input id="field-email" type="email" aria-describedby="field-email-hint" class="p-2 w-full h-10 border border-gray-60 focus:outline-offset-0 focus:outline-4 focus:outline-blue-40v bg-white" />

`} />
