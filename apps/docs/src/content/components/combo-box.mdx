## Component API

### Initialization

```js
import { comboboxInit } from '@uswds-tailwind/compat/combobox'

comboboxInit()
```

`Combobox` is the corresponding instance class. Run initialization after the select options and other parts exist. Time Picker uses this same initializer.

### Anatomy

Set authored attributes in your HTML. The component manages generated attributes. Types describe HTML attribute values.

#### `combobox-root`

Component wrapper.

<ApiTable label="combobox-root attributes">

| Attribute | Type | Description |
| --- | --- | --- |
| `data-default-value` | `string` | **Authored.** Nonempty value overrides the select’s initial value. |
| `data-placeholder` | `string` | **Authored.** Initial placeholder; overrides constructor configuration. |
| `data-disabled` | `presence attribute` | **Authored.** Presence disables the component, including `"false"`. A disabled select also contributes disabled state. |
| `data-disable-filtering` | `presence attribute` | **Authored.** Presence disables filtering, including `"false"`. |

</ApiTable>

#### `combobox-select`

Native select supplying options and the form field name.

<ApiTable label="combobox-select attributes">

| Attribute | Type | Description |
| --- | --- | --- |
| `name` | `string` | **Authored.** Name used for form submission. |
| `required` | `boolean attribute` | **Authored.** Native required-field configuration. |
| `disabled` | `boolean attribute` | **Authored.** Contributes disabled state. |

</ApiTable>

#### `combobox-input`

Text entry control.

#### `combobox-list`

Container for generated options.

#### `combobox-item`

Option template; the wrapper owns generated list items.

#### `combobox-label`

Optional label.

#### `combobox-toggle`

Optional button that opens the list.

#### `combobox-clear`

Optional button that clears selection.

Use each name as its `data-part` value.

Supply nonempty option values and meaningful option text; the empty-value option is excluded from the suggestion list.

Do not store application content or listeners in generated list children, which may be replaced during rendering.

### Lifecycle

The constructor reads configuration from the markup once. Changing data attributes afterward does not update the component. Markup can override constructor options; check the precedence rules in the attribute table.

Retain explicit instances for cleanup and call `destroy()` before removing the component. See [instance lifecycle](/javascript#instance-lifecycle).

### Changes and accessibility

Do not infer a named DOM event from a machine or React callback.

Use the native form controls for submission and preserve labels, hints, and visible focus styles.

The list, options, and expanded/highlighted state are owned by the component; configuration attributes are distinct from generated ARIA and state output.
