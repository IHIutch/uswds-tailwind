---
title: 'Breadcrumb'
description: 'Breadcrumbs provide secondary navigation to help users understand where they are in a website.'
---

## Usage

Breadcrumbs show the current page’s place in the site structure and let users navigate to its parent pages.

## Component API

- Use a `<nav>` with an `aria-label` to identify the breadcrumb navigation.
- Use an ordered list for the path. Parent items are links; the current page is a `<span aria-current="page">` without a link.
- Hide the separator and mobile back arrow from assistive technology with `aria-hidden="true"`.
- Add the `@mobile-lg:truncate` class to the list for the default single-line display. Omit it to allow wrapping.

## Accessibility

- Keep the current page in the breadcrumb trail even though it is not a link.
- Ensure separator icons have sufficient contrast against the background.
