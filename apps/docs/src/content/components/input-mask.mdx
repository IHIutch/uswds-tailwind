## Component API

### Initialization

Run after the component markup exists:

```js
import { inputMaskInit } from '@uswds-tailwind/compat/input-mask'

inputMaskInit()
```

### Anatomy

Set authored attributes in your HTML. The component manages generated attributes. Types describe HTML attribute values.

#### `root`

Wraps the input and mask overlay.

<ApiTable label="input-mask root attributes">

| Attribute | Type | Description |
| --- | --- | --- |
| `data-scope` | `"input-mask"` | **Authored.** Identifies the component scope. |
| `data-part` | `"root"` | **Authored.** Identifies this part. |

</ApiTable>

#### `input`

Required native input.

<ApiTable label="input-mask input attributes">

| Attribute | Type | Description |
| --- | --- | --- |
| `data-part` | `"input"` | **Authored.** Identifies this part. |
| `placeholder` | `string` | **Authored.** Mask format, such as `___-___-____`. The `mask` option takes precedence. |
| `data-charset` | `string` | **Authored.** Character rules, such as `A#A #A#`: `A` accepts a letter and `#` a digit. The `charset` option takes precedence. |
| `value` | `string` | **Authored.** Initial value; the `defaultValue` option takes precedence. |
| `pattern` | `string` | **Authored.** Native browser validation pattern; does not configure the mask. |
| `maxlength` | `integer` | **Generated.** Derived from the mask. |
| `data-placeholder` | `string` | **Generated.** Derived from the mask; the native `placeholder` is removed. |
| `id` | `string` | **Generated.** Defaults to `input-mask:<root-id>:input`; use `ids.input` to override. |

</ApiTable>

#### `content`

Required overlay. The runtime generates children for entered text and the remaining mask. Style the generated `i` with `visibility: hidden` and normal font style to reserve space for entered text.

<ApiTable label="input-mask content attributes">

| Attribute | Type | Description |
| --- | --- | --- |
| `data-part` | `"content"` | **Authored.** Identifies this part. |

</ApiTable>

### Configuration

Pass these JavaScript options to the instance constructor or factory. Authored configuration attributes are read during construction.

<ApiTable label="input-mask JavaScript options">

| Option | Description |
| --- | --- |
| `mask` | `string`. Mask format; overrides the input placeholder. |
| `charset` | `string`. Character rules; overrides `data-charset`. |
| `defaultValue` | `string`. Initial value; overrides the input value. |
| `value` | `string`. Controlled value; takes precedence over the default. |
| `ids.input` | Custom input ID for label composition. |

</ApiTable>

### Methods

<ApiTable label="Input Mask methods">

| Method | Returns | Description |
| --- | --- | --- |
| `api.setValue(value)` | `void` | Requests a formatted value update. |
| `destroy()` | `void` | Stops the instance; does not restore original markup. |

</ApiTable>

```js
import { InputMask } from '@uswds-tailwind/compat/input-mask'

const mask = InputMask.getOrCreateInstance(
  '[data-scope="input-mask"][data-part="root"]',
)

mask.api.setValue('2025550123')
```

See [initialization and cleanup](/javascript#instance-lifecycle).

### Callbacks

<ApiTable label="Input Mask callbacks">

| Callback | Payload | When it runs |
| --- | --- | --- |
| `onValueChange` | `{ value: string }` | The formatted value changes or a controlled change is requested. |

</ApiTable>

Pass callbacks in instance options. These are JavaScript functions, not emitted DOM events.

### Accessibility

- Link the label to the generated input ID, or supply `ids.input`.
- Keep a visible format hint and connect it with `aria-describedby`.
- For a controlled value, your application must supply updates after change callbacks. See [shared lifecycle](/javascript#instance-lifecycle).
