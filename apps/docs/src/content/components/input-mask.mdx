## Vanilla API

Call `inputMaskInit()` from `@uswds-tailwind/compat/input-mask` or include the package's auto initializer. Add `data-part="input-mask-root"` to each wrapper and `data-part="input-mask-input"` to its input. Set the native `placeholder` to the mask format. For mixed letters and numbers, add a `data-charset` pattern such as `A#A #A#` (`A` accepts a letter and `#` accepts a digit). An optional `pattern` attribute validates the completed value.

The optional `data-part="placeholder"` element shows the remaining mask as users type. Keep a visible format hint and connect it to the input with `aria-describedby`.
