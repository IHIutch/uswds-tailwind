## Component API

### Markup

Use a labeled `<nav>` with a list of links. For a collapsible mobile menu, use [Modal](/components/modal) markup and call `modalInit()`. For nested menus, use [Dropdown](/components/dropdown) markup and call `dropdownInit()`.
