## Methodology

For a fair comparison, a representative sample of form controls were compared, basic and enhanced. The totals include JavaScript for the selected components and each library's full default CSS.

React and React DOM are not included in the totals. Together they add about 68.71 KB of gzipped JavaScript to each React library measured.
