## Release changes

- Target the existing `uswds-tailwind` Worker and its `uswds-tailwind.com` custom domain. Use the main domain for canonical, Open Graph, Markdown, robots and sitemap output.
- Preserve `/components/...`, `/getting-started` and `/javascript` links with permanent redirects to Vanilla docs, including query strings. Browser fragments remain on redirects.
- Map existing search hits to the selected library until the post-launch recrawl. Preserve query strings and hashes. The old index can still contain outdated result text or anchors; URL compatibility does not replace reindexing.
- Pin generated Vanilla and React playground dependencies to published `2.0.0-beta.1`.
- Fix the Date Picker demo's custom input ID mapping. Its previous callback returned the same ID for both endpoint indexes; syncing the unused endpoint cleared the visible input. Each endpoint now has a distinct ID.
